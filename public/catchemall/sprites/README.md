# Pokemon regional sprite sheets

Generated by `scripts/build-pokemon-region-sprites.mjs`.

Source atlas: https://pokedextracker.com/pokesprite-v12.png
Source bundle: https://pokedextracker.com/main.0764457964fe78d1c7f1.js
Source forms: https://pokedextracker.com/api/users/wannab/dexes/allllll/captures

The script reads Pokedex Tracker's CSS crop rules, then scales each sprite with nearest-neighbor pixels into fixed 128px cells. It appends every alternate form returned by the same all-dex captures API this page uses, placing each one in its reported generation's regional sheet. Re-run `npm run build:pokemon-sprites` when Pokedex Tracker adds or changes forms.
