# Pokemon regional sprite sheets

Generated by `scripts/build-pokemon-region-sprites.mjs`.

Source atlas: https://pokedextracker.com/pokesprite-v12.png
Source bundle: https://pokedextracker.com/main.0764457964fe78d1c7f1.js

The script reads Pokedex Tracker's default-sprite CSS crop rules, then scales each sprite with nearest-neighbor pixels into fixed 128px cells in national Pokedex order. Re-run `npm run build:pokemon-sprites` only when deliberately updating the pinned source.
